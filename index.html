CALCUL DE LA NOTE FINALE

Comment est attribuée la note EAH finale ?

La note finale repose sur le critère le plus faible. Si le minimum est isolé, +0,5 point est ajouté. S'il apparaît au moins deux fois, la note finale reste ce minimum.

Exemple 1 9 / 9 / 8

Minimum isolé : note finale 8,5.

Exemple 2 8 / 8 / 9

Minimum présent deux fois : note finale 8.

Exemple 3 7 / 6 / 6

Minimum présent deux fois : note finale 6.
